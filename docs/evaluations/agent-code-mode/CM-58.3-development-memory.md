# CM-58.3 Development Memory

## Boundary

CM-58.3 adds the provider-free `cm58.section-leaf-admissibility.v1` safety
layer after CM-58.1 reference admissibility and CM-58.2 report-boundary safety,
and before semantic enrichment. The implementation is based on `cc9d243`.

The layer uses only four bounded booleans projected from the original request:

- `curve_explicit`
- `raster_explicit`
- `section_annotation_explicit`
- `report_note_explicit`

It does not retain normalized request text or planner prose.

## Authorized Rules

1. A raster/image-only section with `track.array`, `binding.raster`, and a
   stray `binding.curve`, but no `track.normal`, loses only `binding.curve`.
   A normal-track variant fails closed as ambiguous.
2. A report-note request without explicit section annotation removes
   `track.annotation` and `annotation.typed` when meaningful plotting content
   remains. Annotation-only pruning fails closed.

Actions are removal-only. The layer never adds, reallocates, splits, merges,
or creates tasks. It revalidates every changed plan through `SemanticPlan` and
`validate_semantic_plan` before enrichment.

## Scope Boundaries

Lichen-style section-local allocation is not repaired; the layer does not add
`track.normal` to a depth-referenced section. Mariner-style provider/schema
failure is not handled because no plan exists for a post-plan safety layer to
inspect. CM-58.2 remains responsible for report-task boundaries and is
unchanged.
