# SI-V2R Failure Taxonomy

## Evidence Boundary

The taxonomy is derived from the immutable SI-V2.2 JSONL only. It does not
claim that the old model emitted V2R. The machine-readable artifact is
`tests/fixtures/semantic_ir_v2r/si_v2_2_failure_taxonomy.json`, generated by
`scripts/semantic_ir_v2r_analysis.py` after verifying the frozen SHA.

The frozen historical SI-V2.2 result remains unchanged: 8/24 stable semantic
passes and 28/48 exact-order final system passes.

No case-specific classifier rule is used. The classifier compares generic

## Reference Adjudication

The four reference-family cases produce eight rows that are compatible with a
section-owned reference interpretation: the generated output preserves data
presentation and carries reference/depth meaning as an additional semantic
feature or companion. This is recorded as `REFERENCE_REPRESENTATION_MISMATCH`,
not as a retroactive SI-V2 pass.

The two overreach rows are retained as `REFERENCE_OVERREACH`. V2R does not
forgive unrequested reference meaning.

## Report Boundary Adjudication

The rows distinguish three failures:

- `REPORT_SCOPE_FALSE_POSITIVE`: report work appeared where the request was
  section-only.
- `REPORT_SCOPE_FALSE_NEGATIVE`: report work was omitted from a mixed request.
- `REPORT_NOTE_SECTION_DUPLICATION`: report-note content was duplicated as a
  section annotation while report work was present.

This preserves the report-worker boundary. CM58 rescue is recorded as a
downstream effect and never changes the model semantic classification.

## Capability Equivalence

The derived final capability comparison reports:

```yaml
exact_order_final_matches: 28
capability_type_equivalent_final_outcomes: 6
order_only_final_mismatches: 6
true_final_capability_mismatches: 0
```

The comparator preserves report type sets, section count and order, and type
sets inside corresponding sections. It rejects duplicates, missing types,
extra types, and reordered sections. Capability ordering within one task is
not semantic for this derived metric. The frozen SI-V2.2 ordered metric is not
replaced.
